# AI+PBL 师生双向选择系统 — 用户故事

> 版本：v0.5
> 修正：每轮后增加"调剂分流"（先老师选、剩余系统统筹）；老师恢复"从调剂范围内选学生"；重新编号
> 句式：作为一个[角色]，我想要[目标]，以便[价值/好处]
> 优先级：**M** = Must / **S** = Should / **C** = Could

---

## 一、学生

### 第一轮 · 学生初选
- **US-01 [M]** 作为一个学生，我想要浏览全部 6 个实训室及其老师，以便做出明智的志愿选择。
- **US-02 [M]** 作为一个学生，我想要查看每位老师的简介（研究方向、介绍、剩余名额），以便决定是否选择该老师。
- **US-03 [M]** 作为一个学生，我想要跨实训室选择最多 3 名老师，以便获得多个匹配机会。
- **US-04 [M]** 作为一个学生，我想要我的 3 个志愿被平等对待、不分先后，以便匹配公平。
- **US-05 [M]** 作为一个学生，我想要设置调剂意愿（实训室内 / 校内，可多选、单选或不选），以便系统在我未被录取时按我的意愿分流。
- **US-06 [S]** 作为一个学生，我想要在初选阶段关闭前修改志愿，以便纠正错误。

### 第一轮 · 面试
- **US-07 [M]** 作为一个学生，我想要查看 3 名志愿老师安排的面试时间表，以便准时参加。
- **US-08 [S]** 作为一个学生，我想要查看面试反馈，以便了解自己的表现。

### 第一轮 · 学生终选
- **US-09 [M]** 作为一个学生，我想要在 2 名及以上老师选中我时收到通知，以便做出最终选择。
- **US-10 [M]** 作为一个学生，我想要从选中我的老师中选择 1 名，以便确定去向。

### 补录轮（第二、三轮）
- **US-11 [M]** 作为一个学生，我想要在某一轮未被录取后收到补录通知，以便参与下一轮填报。
- **US-12 [M]** 作为一个学生，我想要查看所有老师当前的剩余名额，以便补录时合理选择。
- **US-13 [M]** 作为一个学生，我想要在补录轮重新填报 3 名志愿，以便争取录取。
- **US-14 [M]** 作为一个学生，我想要查看补录轮的面试安排，以便参加补录面试。
- **US-15 [S]** 作为一个学生，我想要知道自己处于第几轮补录，以便了解剩余机会。

### 调剂分流
- **US-16 [M]** 作为一个学生，我想要在每轮录取后未录取时，若服从调剂，查看是否被调剂范围内的老师选中或被系统统筹安置，以便了解去向。
- **US-17 [M]** 作为一个学生，我想要在进入待选池时收到通知，以便配合学校约谈安置。

### 通用
- **US-18 [M]** 作为一个学生，我想要查看最终匹配结果，以便知道分配给哪位老师。
- **US-19 [M]** 作为一个学生，我想要全程跟踪状态和所处轮次，以便了解下一步该做什么。

## 二、老师

### 第一轮 · 老师选学生
- **US-20 [M]** 作为一个老师，我想要查看选择我当志愿的学生名单，以便面试和选拔。
- **US-21 [M]** 作为一个老师，我想要只看到选择我的学生（而非全部学生），以便选拔范围正确限制。
- **US-22 [S]** 作为一个老师，我想要为每位学生记录面试成绩和评价，以便做出明智决定。
- **US-23 [M]** 作为一个老师，我想要在名额上限内选择学生，以便实训室获得合适成员。
- **US-24 [M]** 作为一个老师，我想要实时查看剩余名额，以便不超额录取。

### 补录轮
- **US-25 [M]** 作为一个老师，我想要在补录轮查看重新选我的学生并面试，以便继续选拔。
- **US-26 [M]** 作为一个老师，我想要在补录轮继续选择学生补充名额，以便逐步填满实训室。

### 调剂范围内选学生（每轮后分流）
- **US-27 [M]** 作为一个老师，我想要在每轮录取后从调剂范围内的未录取学生中选择，以便补充剩余名额。
- **US-28 [M]** 作为一个老师，我想要在调剂选择时只看到符合范围（实训室内/全校）且有名额的候选学生，以便高效选择。

### 通用
- **US-29 [M]** 作为一个老师，我想要查看最终录取名单（含调剂来的学生），以便为实训做准备。
- **US-30 [S]** 作为一个老师，我想要在我选中的学生也被其他老师选中时收到通知，以便了解冲突需解决。

## 三、管理员

- **US-31 [M]** 作为一个管理员，我想要管理实训室、老师和学生，以便基础数据准确。
- **US-32 [M]** 作为一个管理员，我想要设置每位老师的名额上限，以便名额符合实际。
- **US-33 [M]** 作为一个管理员，我想要开放和关闭各个流程阶段，以便流程按序推进。
- **US-34 [M]** 作为一个管理员，我想要启动和控制每一轮补录，以便按节奏推进录取。
- **US-35 [M]** 作为一个管理员，我想要在每轮结束后公布剩余名额，以便引导学生补录填报。
- **US-36 [S]** 作为一个管理员，我想要配置补录轮数，以便灵活调整录取节奏。
- **US-37 [M]** 作为一个管理员，我想要启动每轮后的系统统筹，以便将老师未选中的服从调剂学生按优先级（实训室内→全院）安置。
- **US-38 [M]** 作为一个管理员，我想要查看待选池学生名单，以便安排约谈。
- **US-39 [M]** 作为一个管理员，我想要对待选池学生约谈后进行人工安置，以便完成最终录取。
- **US-40 [S]** 作为一个管理员，我想要查看统计数据（各轮匹配率、各实训室录取情况、未匹配人数），以便汇报评估。
- **US-41 [S]** 作为一个管理员，我想要导出匹配结果，以便归档并通知相关人员。
